# Roadmap

Este projeto está em desenvolvimento. Os itens sem marcação são planos, não funções disponíveis nem compromissos de prazo. A matriz em [docs/FEATURES.md](docs/FEATURES.md) detalha os limites atuais.

## Base disponível

- [x] Interface navy/roxa responsiva, com esfera neutra.
- [x] Estado inicial vazio, sem dados pessoais ou conteúdo pré-preenchido.
- [x] Tarefas persistentes e percentual de conclusão calculado.
- [x] Agenda local para cadastrar e listar compromissos.
- [x] Importação manual de mensagens e notas pesquisáveis.
- [x] Integração com a API local do Ollama e histórico persistente.
- [x] Auditoria de operações e backup criptografado com restauração.
- [x] Testes de persistência, validação, criptografia e proteção da API local.

## Próxima validação

- [ ] Testar geração real com Ollama e um modelo instalado.
- [ ] Validar ditado e leitura em navegadores compatíveis.
- [ ] Ampliar a validação de acessibilidade e compatibilidade.
- [ ] Melhorar mensagens de erro, reconexão e ergonomia da interface.

## Capacidades planejadas

- [ ] Alertas da agenda e lembretes.
- [ ] Executor de automações com confirmações e cancelamento.
- [ ] Ferramentas de arquivos com raízes permitidas e testes de contenção.
- [ ] Microagentes de pesquisa somente leitura.
- [ ] Pesquisa web com fontes verificáveis.
- [ ] Voz offline, independente do serviço do navegador.
- [ ] Suporte a llama.cpp e escolha adaptativa de modelos.
- [ ] Busca no histórico e evolução da memória local.
- [ ] Laboratório de habilidades e estudo periódico controlado.
- [ ] Backup agendado.
- [ ] Overlay e empacotamento desktop.
- [ ] Atualizações verificadas e documentação de distribuição.

## Como contribuir

Abra uma issue com o problema observado, passos para reproduzir e comportamento esperado. Não inclua dados pessoais, mensagens privadas, backups, credenciais ou conteúdo do seu workspace. Propostas de integração devem explicar permissões, armazenamento e como testar sem compartilhar dados particulares.
